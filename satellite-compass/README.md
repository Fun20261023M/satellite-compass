# satellite-compass

卫星调星助手 - 实时罗盘对星工具

## 功能

- 输入经纬度或自动定位获取当前位置
- 选择目标卫星（预置13颗常用卫星 + 自定义经度）
- 选择天线类型（偏馈/正馈）和尺寸
- 计算调星角度：方位角、仰角、极化角
- 实时罗盘显示手机朝向与目标卫星方向对比
- 支持方向传感器（需 HTTPS 环境）

## 使用方法

1. 将 `satellite-compass/index.html` 部署到任意 HTTPS 服务器（Vercel/Netlify 支持静态文件拖拽部署）
2. 用手机浏览器打开部署链接
3. 允许定位和方向传感器权限
4. 输入纬度经度（或点击获取当前位置）
5. 选择卫星和天线类型，点击计算
6. 按照罗盘指示调整天线方向

## 注意事项

- 必须在 HTTPS 环境下使用，否则方向传感器不可用
- iOS 设备需要手动点击授权按钮允许方向传感器
- 计算结果为理论值，实际调星需结合接收机信号质量微调
- 偏馈天线支架刻度 = 计算仰角 - 偏馈角
